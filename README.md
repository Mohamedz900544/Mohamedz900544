## Featured Project

### KidGuard Graduation Project

Smartwatch-based child safety monitoring platform.

What the system includes:

- Flutter parent mobile app
- Wear OS smartwatch app
- Node.js and TypeScript backend API
- MongoDB data models for users, watch data, alerts, audio, zones, and emergency contacts
- Geofencing and safety notifications
- AI pipeline for audio emotion signals, Arabic safety classification, and danger assessment
